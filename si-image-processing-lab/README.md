# si-image-processing-lab

Laboratorio UCV de procesamiento de imágenes con Kedro, Poetry, GitHub Actions y SonarQube/SonarCloud.

## Objetivo

Implementar un pipeline profesional de procesamiento de imágenes utilizando Python, Kedro y Pillow, aplicando buenas prácticas de ingeniería de software como Poetry, Pull Requests, GitHub Actions, Pytest, Ruff y SonarCloud.

## Ejecución local

```bash
poetry install
poetry run pytest
poetry run ruff check .
poetry run kedro run
```
